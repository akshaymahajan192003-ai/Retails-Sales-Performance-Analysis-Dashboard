## Project Overview
This project analyzes retail sales data to identify top-performing product categories, revenue trends, and key business insights.

## Tools & Technologies Used
- **Python (Pandas, Matplotlib/Seaborn):** Data cleaning and exploratory data analysis (EDA)
- **MySQL:** Querying, aggregating, and analyzing transactional data
- **Power BI / Excel:** Interactive dashboards and data visualization

## Key Features & Analysis
- Cleaned raw dataset by handling missing values and data inconsistencies.
- Performed SQL queries to calculate monthly sales growth and regional metrics.
- Built interactive dashboards to visualize key performance indicators (KPIs).

## How to Run
1. Clone this repository.
2. Open Jupyter Notebook / SQL scripts to view analysis code.
